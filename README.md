# student-task-manager
A simple web-based application for managing student tasks

## Usage

1. Open the Student Task Manager in your web browser.
2. Enter a task in the input field.
3. Click Add Task to add it to the list.
4. Click Complete to mark a task as finished.
5. Click Undo to restore a completed task.
6. Click Delete to remove a task.

## Project Structure

- index.html - Main application interface
- style.css - Application styling
- script.js - Task management functionality
